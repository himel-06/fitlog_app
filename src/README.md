# 🏋️ FitLog — Workout Library

A dark, no-nonsense gym companion: browse a library of lifts, lock them into today's plan, and watch your daily totals add up.

**Live:** <your-deployed-url>

## Technologies Used
- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
- lucide-react (icons)
- react-hot-toast (notifications)

## Key Features
1. **Workout Library** – 12 lifts in a responsive grid with a Duration / Calories / Rating sort.
2. **Detail Pages** – specs table, 4-step instructions, add-to-plan and save buttons.
3. **My Plan Dashboard** – live Exercises / Minutes / Calories totals with Today's Plan and Saved tabs.
4. **Plan Actions** – mark as done, remove, 5-lift daily cap, and toast feedback.
5. **Persistent & Responsive** – data survives reloads via localStorage, plus a custom 404 and mobile-first layout.

## Getting Started
```bash
npm install
npm run dev
```
